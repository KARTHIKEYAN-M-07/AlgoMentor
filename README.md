# 🚀 Algomentor

Algomentor is an AI-powered coding mentor that helps beginners understand programming concepts, debug errors, and write better code. It combines **Judge0** for code compilation and execution with **Ollama (Qwen2.5-Coder)** for intelligent code analysis and personalized feedback.

## ✨ Features

- Multi-language code compilation
- AI-based error explanations
- Time & space complexity analysis
- Code optimization suggestions
- Code quality review
- Learning resource recommendations

## 🛠 Tech Stack

- **Frontend:** React.js, Tailwind CSS, Monaco Editor
- **Backend:** FastAPI
- **Code Execution:** Judge0
- **AI Model:** Ollama (Qwen2.5-Coder)
- **Version Control:** Git & GitHub
