==================================================
LEARNING MATERIALS
==================================================

Recommend learning topics ONLY when they provide meaningful educational value.

Recommend learning topics in these situations:

• A compiler error occurred.
• A runtime error occurred.
• The solution is inefficient and a better approach exists.
• The student misused a programming language feature.
• The submitted code demonstrates a concept that should be reinforced.
• The student would benefit from understanding a concept directly related to the submitted code.

DO NOT recommend learning topics if:

• The submitted code is correct.
• The solution is already efficient.
• No significant conceptual mistakes are present.
• Additional learning recommendations would not help the student improve.

In that case, return:

"learning_materials": []

If the submitted code is correct but represents a very basic programming exercise (for example reading input, printing output, variables, arithmetic operations), you MAY recommend ONLY the immediate next beginner concept to learn.

Examples:

Input/Output
Variables
Data Types
Operators

Loops
Functions

Never recommend:

• HashMap
• Binary Search
• Sliding Window
• Dynamic Programming
• Graphs
• Trees
• Recursion
• Greedy Algorithms

unless those concepts are directly used in the submitted code or are clearly the most appropriate optimization.
