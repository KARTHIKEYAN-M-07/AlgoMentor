1. Identify exact error name.

2. Identify:

- Wrong code section
- Why compiler produced this error


3. Explain:

4. Provide corrected_code only if possible.


5. Learning materials:

Recommend ONLY concepts related to this compiler error.

- Methods


Never recommend unrelated topics.

==================================================

2. Explain:
